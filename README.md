# 氿悦体育新版官网

本仓库独立保存 2026 年 9 月 12 日确认的官网设计与生产前端，目标域名为 https://jiuyue.club/ 。旧仓库 `jiuyue-sports-site-local-2026` 保留历史版本；本仓库的 `main` 是这次新版的维护入口。

网站采用紫色视觉体系，提供课程比较、真实课堂、家长指南、教学与公开资质、到店指引及预约咨询。共 16 个正常页面和 1 个 404 页面。课程年龄、班次、费用与具体集合位置仍需预约确认，以实际安排为准。

## 源码与本机预览

`dist/` 中的 HTML、CSS、JavaScript 即完整可编辑的静态源码，无需打包框架。媒体素材是原官网已经公开使用的图片、课堂视频及脱敏资质。直接修改对应页面或公共样式、脚本即可维护。

```sh
python -m http.server 8787 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:8787/ 查看。此命令只提供静态页面；本机预约接口不会连接生产数据库。

## 功能与隐私

- 生产预约使用同域 `/api/inquiries`，保留必需的信息处理确认、失败保留内容、成功清空及提交期间防重复行为。
- 预约页提供电话及微信咨询入口；微信二维码为经用户授权公开的原图，支持查看和保存。
- 访问统计仅在用户主动同意后启用，拒绝不影响预约，可从页脚设置撤回。
- 服务器继续提供原有预约后端、电脑后台与手机后台；本仓库不包含客户数据、管理员凭据、服务器凭据或本地知识库。
- canonical、站点地图使用正式域名；公开页面允许抓取，后台/API 不参与搜索收录。

## 抖音团购入口

首页与课程页首屏、全站页脚和手机底栏共用氿悦体育抖音门店链接：<https://v.douyin.com/x-sedAQA0Uc/>。家长点击后前往抖音查看在售套餐，价格及使用规则以抖音页面为准；电话与页面内预约咨询入口继续保留。

套餐在抖音门店维护，无需逐款同步到官网。门店分享链接如发生变更，统一替换 `dist/**/*.html` 中的上述地址，并更新此说明；发布前核验链接及运行静态检查。官网使用普通 HTTPS 链接，不自动唤起应用或代为下单。

## 检查与发布

### 轻盈玻璃界面

全站沿用原有课程、课堂照片和文案，导航、筛选及咨询入口使用局部玻璃材质。样式集中在 `assets/production.css` 的轻盈玻璃分节，由 `body.liquid-glass-ui` 限定作用域；课堂筛选的移动高光由 `assets/design.js` 渐进增强。减少动态效果偏好、无背景模糊支持和高对比模式均有对应样式。

服务器自动拉取器只接受初始化时登记的精确 `dist/` 文件集，因此本次复用既有资源路径；不要仅通过新增 CSS/JS 文件的方式绕过部署白名单。样式或脚本变化时，同时更新页面引用的版本参数，避免浏览器继续使用缓存。

### 验证

```sh
python tests/check_site.py
node --test tests/booking.test.cjs tests/analytics.test.cjs tests/legacy-navigation.test.cjs
python -m unittest discover -s tests -p "test_*.py"
```

可用安装了 Playwright 与 Chromium 的环境运行浏览器回归。先启动上述本地预览，再运行：

```powershell
$env:GLASS_BASE_URL = 'http://127.0.0.1:8787'
node tests/liquid-glass.browser.cjs
```

如果 Playwright 由宿主统一提供，可将 `PLAYWRIGHT_MODULE` 设为其模块目录。检查覆盖课堂深链筛选、换行后高光定位、减少动态效果、手机菜单键盘关闭及预约/微信入口；测试拦截 API 请求，不提交实际预约。

发布程序及说明见 `scripts/`。仅从已提交并推送的干净版本生成前端发布包，先核对服务器当前配置摘要和前端版本，再切换；保留旧版本目录和配置备份供回退。Nginx 仅增加明确的前台资源路径，不覆盖 `/admin`、`/api/` 或原后台使用的静态资源。

仓库已按用户要求公开，网站也公开访问。本次设计与既有品牌、摄影和课堂素材的权利仍归相应权利人，不因上传代码改变授权范围。
